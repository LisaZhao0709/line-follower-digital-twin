Model assumptions and limits

The source uses differential-drive kinematics, eight-channel map sampling and discrete PID. The receiver predicts from the previous synchronized state and nominal speeds, then corrects from new observations and computes wheel-speed residuals. Orange markers show prior predictions. Python and MATLAB share the track and equations; their random generators differ, so seed reproducibility applies within each implementation.

Recommendations use teaching rules; optical and ground disturbances still require physical calibration. The source is a software simulation. In addition to the mathematical model, this application implements asset identity, online observations, state updates, analysis and command feedback.
