# 完整八周工程使用说明

八周课程核心功能已经完成：二维赛道、8路灰度、差速运动、P/PD/PID、积分保护、三参数学生界面、量化提示和完整实验记录。所有阶段均经实际 MATLAB/Simulink 检查；最终25组实验通过1063项独立复算。

## 打开学生界面

当前电脑在 MATLAB 命令窗口执行：

```matlab
cd('<repository>\full_project')
START_PROJECT
```

解压到其他文件夹时，将 `cd` 的路径换为解压后的 `full_project` 目录。已有模型及地图完整保存在工程中，正常使用不需要 Python，不需要手动拖放模块。

1. 修改Kp、Ki、Kd后点击“运行新实验”。允许范围分别为0–20、0–2、0–0.5；非数值、无穷大和范围外输入会拒绝。
2. 每次运行清空模型内部积分、微分滤波、上一误差和停车锁定状态，重新从同一初始位置计算。
3. 计算完成后点击“播放”，观察地图、车身、8路传感器、误差、P/I/D、左右命令、仿真轮速、残差及提示。
4. “暂停”和“单步”控制已记录轨迹的播放。“复位”返回记录的初始帧；点击“运行新实验”才重新计算并初始化模型。播放约4倍速，不声称实时计算。
5. 参数只在下一次实验生效；计算中按钮和参数暂时禁用。
6. 新实验自动写入 `results/experiments/run_时间`，已有复核记录不会覆盖。目录含CSV、MAT、JSON、模型快照、检查及日志。

## 固定演示的三组参数

| 目的 | Kp | Ki | Kd | 已验证行为 |
|---|---:|---:|---:|---|
| 响应不足 | 0.05 | 0 | 0 | 转弯时偏差增大，14.76 s脱线停车 |
| 默认完整PID | 0.45 | 0.015 | 0.03 | 约87.50 s完成一圈；局部窗口仍可能提示偏慢 |
| 强P振荡及饱和 | 15 | 0 | 0 | 频繁交换左右输出，运行时饱和约85.93% |

可进一步比较 `3/0/0`、`0.45/1/0.03`。这两组在当前理想模型中的误差比默认组更小；默认不是最优参数，“参数大”也不等同于“效果差”。圈时快慢会受到电机饱和导致平均速度变化的影响。

## 随机灰度与环境实验

在学生界面右上角选择“轻度光照/阴影/颠簸”或“较强光照/阴影/颠簸”，填写整数种子后点击“运行新实验”。灰色曲线显示当前位姿下的理想灰度，蓝色曲线显示进入控制器的实际灰度。相同环境、种子、采样周期和实验时长可重复比较 PID，改变种子可以比较不同随机工况。启动时载入的冻结轨迹属于理想环境，摘要会标明当前记录使用的环境。

脚本入口如下。环境等级 0 为理想，1 为轻度，2 为较强。

```matlab
extra = struct('environment_level',1,'environment_seed',7);
[record,trace,cfg,directory] = run_twin_experiment(0.45,0.015,0.03,extra);
```

新增扰动包括相关时间分别约为 2 秒的光照增益变化、0.8 秒的随机遮光、0.08 秒的传感器前后/左右采样位置偏移，以及各路独立读数噪声和固定偏置。轻度环境的读数噪声标准差为 0.015，采样位置偏移标准差为 0.6 mm；较强环境分别为 0.06、2 mm。灰度先受扰动再限幅至 [0,1]，随后阈值判定和 PID 均使用这一实际观测值。地面影响以传感器位置抖动近似，扰动幅度是教学假设，需要实测标定。

新 CSV 记录 `ideal_strength1..8`、`sampled_strength1..8`、实际 `strength1..8`、二值 `S1..8`，并保存光照增益、阴影偏置、位置抖动和各路读数误差。JSON 保存环境等级和随机种子。`record.sensor_strength_rmse` 和 `record.sensor_bit_error_fraction` 将实际观测与同一车辆位姿下的理想值对照，度量传感器误差；`record.mae` 则度量控制器收到的循迹误差。两者应分别解读。

执行 `validate_environment` 可重跑理想基线、随机种子重复、换种子、强扰动、强制丢线和界面实验。首个启动会自动更新传感器模块，并将旧模型保存到 `models/backups`。已有未保存的模型编辑需要先保存。

2026-11-03 的[实际仿真记录](results/environment_20261103_110516/summary.csv)中，默认 PID 在理想环境下 87.503477 s 完圈，轻度环境、种子 7 下为 87.648843 s；同种子重复轨迹完全相同，种子 8 下为 87.638259 s。较强环境、种子 7 下于 25.18 s 脱线停车，强制中断实验在 1.20 s 停车。验证覆盖 7 组脚本实验与 1 次界面新实验，另有 Python 对 7 组原始记录完成[241 项独立公式复核](results/environment_20261103_110516/independent_checks.json)。这些结果对应当前地图和参数。

## 查看模型或运行脚本实验

```matlab
OPEN_MODEL
[record,trace,cfg,directory] = run_twin_experiment(0.45,0.015,0.03);
```

教师扰动实验示例：

```matlab
% 从1秒起中断0.4秒；满0.2秒后停车，并保持锁定。
run_twin_experiment(0.45,0.015,0.03, ...
    struct('dropout_start_s',1,'dropout_duration_s',0.4,'stop_time',3));

% 左侧仿真电机速度比标称预期低20%，显示模型残差。
run_twin_experiment(0.45,0.015,0.03,struct('motor_left_factor',0.8));
```

## 查阅冻结实验及重跑验收

`results/week5_latest.txt` 到 `week8_latest.txt` 指向通过的阶段记录。完整报告、独立检查表、性能表、地图检查、界面截图和动画都在第8周目录。

完整工程压缩包位于上一层目录。包内 `full_project` 是可直接使用的最终工程，`weeks1_4` 保存前四周教学模型及冻结复核证据。

```matlab
RUN_ALL_WEEKS
```

此命令依次执行第5→6→7→8周，任何检查失败立即停止，然后进行Python独立复核和打包。当前电脑使用 `D:\ide\Anaconda\python.exe`。其他电脑可显式指定：

```matlab
RUN_ALL_WEEKS('C:\your-python\python.exe')
```

独立复核需Python及numpy、scipy、pandas、matplotlib、Pillow。仅使用学生界面无需安装这些库。
