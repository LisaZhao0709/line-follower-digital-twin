# 使用复核后的解析运动学模型

此版本已检查参数单位、地图拓扑、控制公式、积分误差、跑圈计时、脱线时限、复位和采样周期敏感性。完整结果位于 `results/review_20261004_235432/复核与准确仿真报告.md`。较早的验收表属于历史版本，最终结果以本轮冻结快照为准。

在 MATLAB 命令窗口执行：

```matlab
cd('<repository>\weeks1_4')
OPEN_REVIEWED_SIMULATION
```

这个入口会打开 `LF_Week4_PD_Exact.slx` 和本轮实际仿真的默认PD结果。模型已保存地图和参数，可以直接运行。

播放本轮已验证轨迹：

```matlab
play_reviewed_run
```

运行新的实验，自动保留独立记录：

```matlab
run_accurate_demo('P', 0.45)
run_accurate_demo('PD', 0.45, 0.03)
```

每次实验写入 `results/experiments/exact_时间戳/`，不会覆盖本轮复核数据。它包含原始SimulationOutput、逐样本CSV、参数JSON、方程校验表、模型副本、运行日志和曲线。临时实验参数不会永久改写模型默认值。

想重新执行整套检查时：

```matlab
run_detailed_review
```

这会新建复核目录，并执行12项开环解析解对比、12组实际仿真和相应MATLAB校验。用于开发的 `tools/independent_review.py` 可另行对新目录执行独立Python复算与报告生成，需要本机已有 NumPy、SciPy、Pandas、Matplotlib；日常运行模型无需Python。

数值精度的改善来自单周期解析运动增量，传感器和控制器默认仍为50Hz。新增块 `HalfTurn`、`MidpointHeading`、`ArcFactor`、`EffectiveSpeed` 位于 `DifferentialDrive` 内，可以双击查看。两个原教学模型保留用于理解欧拉积分；脱线计时已同步修正为从首次失线采样时刻起完整0.20秒。

本轮默认参数下，解析P约87.59s跑完一圈，解析PD约87.52s；20ms与5ms采样的PD圈时相差约4.30ms。表中的更多小数来自门线内插，不代表实车测量精度。地图比例、车轮距、轮速系数和传感器几何仍有未实测的假设，需后续标定才能评价真实小车精度。
